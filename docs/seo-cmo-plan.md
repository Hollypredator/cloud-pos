# Cloud POS SEO / CMO Growth Plan

## Positioning
Cloud POS should rank for high-intent restaurant, cafe, QR menü, self-service ordering, adisyon, inventory and cloud POS searches in Turkey first, then English-speaking global searches.

## Keyword Clusters
| Cluster | Primary intent | Core URLs |
|---|---|---|
| Restaurant POS | Restaurant owners comparing POS systems | `/restoran-pos-sistemi`, `/en/restaurant-pos-system` |
| Cafe POS | Cafes and coffee shops needing fast checkout and pickup | `/kafe-pos-sistemi`, `/en/cafe-pos-system` |
| QR Menu | Digital menü and table ordering buyers | `/qr-menü`, `/en/qr-menü-system`, `/izmir-qr-menü` |
| Self-Service | Pickup, quick service and self-ordering flows | `/self-servis-siparis-sistemi`, `/en/self-service-ordering-system` |
| Inventory POS | Buyers looking for stock-aware POS | `/stok-takipli-pos-sistemi`, `/en/cloud-pos-system` |
| Adisyon | Restaurants comparing check/table account software | `/adisyon-programi` |
| Mobile Waiter | Waiter handheld and mobile ordering alternatives | `/garson-el-terminali` |
| Local Turkey | City + business-type search intent | `/istanbul-restoran-pos-sistemi`, `/ankara-kafe-pos-sistemi`, `/izmir-qr-menü` |

## 30 / 60 / 90 Day Targets
| Window | Focus | Target signals |
|---|---|---|
| 30 days | Indexing and technical validation | All SEO URLs indexed, sitemap discovered, no duplicate title/canonical errors |
| 60 days | Query discovery | Impressions on core Turkish clusters, early long-tail clicks, visible CTR baseline |
| 90 days | Ranking improvement | Top 20 positions for several long-tail local and product queries, increasing demo/login CTA path clicks |

## Search Console Reporting
Review weekly:
- Impressions by page group: TR product, EN product, local Turkey.
- Clicks and CTR by query cluster.
- Average position for target terms: `restoran pos sistemi`, `qr menü`, `kafe pos sistemi`, `adisyon programı`, `cloud pos system`.
- Indexed pages and excluded pages.
- Pages with duplicate title, alternate canonical or soft 404 warnings.

## Funnel Metrics
Track from SEO pages:
- `/demo` clicks.
- `/login` or operations-panel CTA clicks.
- Contact or lead form submissions if enabled.
- Query cluster to landing page to demo path.

## Guardrails
- Do not generate thin city pages at scale.
- Do not add LocalBusiness schema unless a real verifiable business address is available.
- Keep pages static where possible to avoid operational database load.
- Every new SEO page must have unique title, description, canonical, structured data and sitemap entry.
